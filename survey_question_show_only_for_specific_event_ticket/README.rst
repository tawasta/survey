====================================================
Survey Question: Show Only for Specific Event Ticket
====================================================

* Enables configuring event survey questions so that 
  they are only shown/asked when the registrant is 
  purchasing a specific ticket.


Configuration
=============
* In the question form view, select the tickets 
  you want in the new 'Show only for Specific 
  Event Tickets' field. Leave empty to show 
  the question normally.

Usage
=====
* Register for an event on the website. Question is shown
  or hidden in the event survey according to the question
  configuration.
