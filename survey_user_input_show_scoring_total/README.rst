=========================================
Survey User Input: Show Total Score Field
=========================================

This module shows the numeric total score on a survey participation,
next to the score percentage that is already visible by default.

Configuration
=============
\-

Usage
=====

#. Open a survey participation (Survey > Participations).
#. The **Total Score** field is shown next to **Score (%)**, whenever
   the survey uses scoring.
