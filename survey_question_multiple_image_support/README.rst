=======================================
Survey Question Multiple Image Support
=======================================

Enables adding multiple images to survey questions. Supports language-specific images 
and adds survey language, to help with image management. 


Configuration
=============
* Install the module

Usage
=====
* Add survey languages in configuration
* Make a survey and add section
* Add a question to a section
* Go to Image settings tab and add language specific image(s)
