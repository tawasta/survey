==========================================================
Survey User Input Form: Quick Links to Answers' Edit Views
==========================================================

* Glue module between survey_user_input_line_quick_link_to_edit 
  and survey_user_input_parent_survey_user_input_link
* Provides the answer editing quick button also to the followup 
  survey's answer lines 

Configuration
=============
* None needed

Usage
=====
* Just open the participation form as a survey manager to see the new
  buttons on answer lines
