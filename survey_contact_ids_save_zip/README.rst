========================
Survey Contacts Save Zip
========================

This module lets a text-answer survey question save the respondent's
answer as a zip code, either on the survey participation's own partner
or on one of the survey's contact persons.

Configuration
=============

#. Open a survey question of type **Text Answer**.
#. Check **Save as partner zip** to save the answer as the
   participation's partner's zip code.
#. Check **Save as contact zip** to save the answer as the zip code of
   one of the survey's contact persons (pick which contact with the
   **Contact Number** field).
