==========================================================
Survey User Input Form: Quick Links to Answers' Edit Views
==========================================================

* Survey Managers see buttons that point to each answer's editing view,
  removing the need to navigate to editing via "Detailed Answers" menu
* Keeps the answer list view readonly, so editing access is not 
  available for everyone

Configuration
=============
* None needed

Usage
=====
* Just open the participation form as a survey manager to see the new
  buttons on answer lines

Known issues / Roadmap
======================
