====================================
Survey User Input Report XLSX Scores
====================================

This module extends the survey participations XLSX report with an
additional sheet showing the scores behind each answer, and a reference
table of correct answers and their point values for every scored
question.

Configuration
=============
\-

Usage
=====

#. Go to **Survey > Participations**.
#. Select one or more participations and print **Print Survey
   Participations to XLSX**.
#. The downloaded file now has a "Survey Answer Scores" sheet in
   addition to the regular answers sheet.
