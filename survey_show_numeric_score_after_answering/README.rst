==========================================
Survey: Show Numeric Score After Answering
==========================================

This module lets a participant see their achieved numeric score on the
"thank you" page after finishing a scored survey.

Configuration
=============

#. Open a survey.
#. Enable scoring (with or without answers at the end) and add some
   scored questions.
#. Check the new "Show Numeric Score to Participant" checkbox.

Usage
=====

#. Answer the survey. On the "thank you" page, the total score is
   shown.

Known issues / Roadmap
======================
* Possible extra features: showing individual scores per question,
  configurable messages per score range.
