================================
Survey Portal Upload Attachments
================================
* Upload attachments to surveys from portal  
* Attachments can be uploaded to existing attachment questions on Survey  

Configuration
=============
- Add "Attachment" type questions to your survey  
- Enable "Allow portal file upload" on each question where uploading should be possible  
- Optional: configure file type and max size validation per question  

Usage
=====
1. Go to Portal > My Survey Answers  
2. Press **Upload Attachments** on the relevant answer  
3. Select files for each attachment question in the modal  
4. Click **Upload Attachments** to save files  
5. Note: `survey_stages` module (if installed) defines when attachments can be uploaded
