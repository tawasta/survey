===============================================
survey_customizable_frontend_terms_and_elements
===============================================
This module allows you to define a **custom label** for the **"Start Survey"** button in the Odoo survey frontend.

Features
============
- Add a custom label for the *Start Survey* / *Start Certification* button.
- Translatable per survey.
- Falls back to Odoo default if the field is empty.

Configuration
=============
1. Open a survey in *Surveys > Surveys*
2. Go to the new tab **Answer settings**
3. Enter custom text into **Answer Button Text**
4. Save

Usage
=====
When a user opens the public survey page, your custom button text will be shown instead of the default *Start Survey* or *Start Certification*.

Leave the field empty to use the default core text.
